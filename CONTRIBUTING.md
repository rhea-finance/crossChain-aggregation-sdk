# Contributing Guide

Thank you for your interest in Cross-chain DEX Aggregation SDK! We welcome all forms of contributions.

## Development Environment Setup

1. Fork and clone the repository
2. Install dependencies:
   ```bash
   pnpm install
   ```
3. Run type checking:
   ```bash
   pnpm type-check
   ```
4. Build the project:
   ```bash
   pnpm build
   ```

## Code Standards

- Write code in TypeScript
- Follow existing code style
- Add appropriate comments and documentation
- Ensure all type definitions are correct

## Submitting Pull Requests

1. Create a feature branch
2. Make your changes
3. Ensure all tests pass
4. Submit PR and describe your changes

## Reporting Issues

Please report issues in GitHub Issues and provide:
- Issue description
- Reproduction steps
- Expected behavior
- Actual behavior
- Environment information
